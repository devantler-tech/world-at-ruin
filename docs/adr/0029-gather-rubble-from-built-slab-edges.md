# Gather cosmetic rubble from built exposed-stone edges

> 🤖 Generated by the Agentic Engineer

Status: Accepted for the default-off preview

## Context

Raised stone has deterministic top polygons, but their lips end abruptly against
the ash. Issue #549 calls for chips and grit gathered at selected weathered
edges, rather than another unrelated world scatter. The base terrain, existing
foliage, solid tops and player state must remain unchanged.

## Decision

The geometry build records each top's stable slab identity and the ash cover
immediately outside its original polygon edges. These are additive source
records, not a new mesh or a second exposure field. A pure placement helper uses
those records to select ash-facing fracture edges. Shared raised-stone edges
and protected landmark approaches reject the apron.

Each selected edge supplies a small outward cluster: larger chips beside the
lip, smaller grit further into the ash. Edge-local integer hashes control the
variation. A ranked, bounded selection distributes aprons without depending on
the process random stream or modifying the original foliage scatter. The
source slab/edge and accepted placements remain inspectable separately from the
closed cosmetic placement schema. An accepted apron retains at least one larger
lip cluster and two smaller grit clusters; it cannot survive as unrelated grit
after all of its larger chips are blocked.

Clearance uses a yaw-independent radius enclosing the actual generated mesh,
then applies the instance scale. Exact circle/polygon segment distances reject
partial overlaps with raised tops, including thin polygons that contain no
sampled centre or corner. Protected circles compare the sum of both radii.
Placement queries reuse the world's existing raised-top index, checking at
most nine nearby 2 m cells. They neither build a second grid nor scan the whole
world for each instance.

One additional MultiMesh reuses the existing generated rubble mesh and opaque
material, with shadow casting disabled. Source records, apron count and total
instances have explicit bounds: at most 192 aprons and 1,152 cluster instances.
Each instance reuses a mesh containing four stone chunks; those chunks are not
independent draw instances. Rubble has no collision, save data or reward.
The cosmetic batch belongs beneath the existing `GroundPlates` node, keeping
the world's top-level node inventory unchanged. The base-owned regression
continues to require exactly the original overlay and its collision body.
The starter cave doorway apron, cave footprint, shrine clearing and ruin
footprints remain clear.

The existing exact `WAR_GROUND_PLATES=1` opt-in owns this treatment, following
ADR 0001. Default and malformed flag values build no rubble. Live opt-out hides
the batch; repeated opt-in reuses its original transforms. Evidence tools may
hide just the cosmetic batch to compare the same build with and without it.

## Consequences

Native tests hold edge provenance, ash association, clear intact neighbours,
partial footprint overlaps, keep-outs, graded scale, deterministic count bounds
and the fresh-boot/live-toggle boundary.
Existing terrain, plate collision and foliage fingerprints remain independent.
Windowed captures judge the actual transition at close and grazing distances.

This does not activate raised stone or clear the GPU budget, regional exposure,
the parent material acceptance or the maintainer's Phase 0 taste gate. The
preview can still show repeated generated cluster silhouettes and lacks contact
shadows; those are visual judgment questions, not passed by determinism tests.
